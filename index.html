      How we build the map

      Red areas and pins come only from named news reports. Pins sit on the street or square, not the exact shop door. Amber-marked sources are single or weaker sources.

      Updating it

      All incidents live in data.js. The open page re-reads that file every 60 seconds, so new zones, shops and numbers appear without a reload.
